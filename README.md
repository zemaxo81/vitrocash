# VITROCASH

Application de divertissement locale et hors connexion, à **crédits fictifs** sans aucune valeur monétaire :
tickets à gratter, roue, bandit manchot, loterie quotidienne, chronomètre, paliers, historique et espace administrateur.

Toutes les données restent sur l'appareil (aucun serveur, aucun compte).

## Lancer en local
```
npm install
npm run dev
```

## Publication
Chaque modification envoyée sur la branche `main` est construite et publiée automatiquement sur GitHub Pages
(voir `.github/workflows/deploy.yml`).
